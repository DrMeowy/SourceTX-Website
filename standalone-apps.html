Use these apps for the complete guided workflow: factory installation, updates, recovery, and model backup or restore. The browser alpha is available separately for supported desktop USB work.

DESKTOP / USB

Windows Companion

v0.1.5

The maintenance desk for a supported ESP32-S3 transmitter.

  • Install a signed factory image on a blank supported board.
  • Update or repair firmware with exact chip and flash preflight.
  • Back up the active model or every configured model as a bundle.
  • Restore only after schema, checksum, and transmitter acknowledgement.

Android Companion

v0.2.8

A phone-first path for signed maintenance and model backups.

  • Install the verified factory image on the official 4 MB target.
  • Download signed stable updates while preserving model storage.
  • Export and validate .stxm or .stxb backups.
  • Works without analytics, accounts, or uploaded model data.
