browser alpha / firmware installation

Install or update SourceTX over USB.

The factory action writes the complete signed image. The update action writes only the verified application at its expected offset and preserves the transmitter’s model storage.

REQUIREDPC with Chrome or Edge

Open this page over HTTPS so Web Serial and local signature verification are available.

TARGETSourceTX ESP32-S3 / 4 MB

The browser tool rejects releases for other chips, flash sizes, or hardware IDs.

CABLEUSB data cable

Charge-only cables cannot expose the transmitter serial port.

RECOVERYBOOT → RESET → release

For a blank board, hold BOOT, tap RESET, then release BOOT before selecting the port.

CLI equivalent / detailed recovery

The browser tool uses the same release contract as the companion apps. Download the signed release artifact from SourceTX Updates, verify its checksum and signature, then use the matching offset.

# Factory image — full recovery
python -m esptool --chip esp32s3 --port PORT --baud 460800 write-flash --flash-mode dio --flash-freq 80m --flash-size 4MB 0x0000 SourceTX-vX.Y-factory.bin

# Application update — preserve model storage
python -m esptool --chip esp32s3 --port PORT --baud 460800 write-flash 0x10000 SourceTX-vX.Y.bin

Do not write the application image at 0x0000. A factory image and an application image are different artifacts.
