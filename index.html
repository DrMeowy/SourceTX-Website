    !Never power a radio module, motor, speaker, haptic motor, or high-current LED from an ESP32 GPIO.

    a safer first run

    Start with the vehicle restrained.

    The shortest path to a good first drive is a careful one. SourceTX gives you the checkpoints; the builder still owns the hardware and the load.

    Read the user manual ↗
    1. 01
      Confirm the target.

      Match the ESP32-S3, flash, PSRAM, display, touch controller, pins, module, and antenna to the reference.

    2. 02
      Install through a companion.

      Use the signed factory flow for a blank board, or the signed OTA path for a compatible running unit.

    3. 03
      Calibrate with drive power off.

      Center controls, verify direction and endpoints, select the intended model, and configure receiver failsafe.

    4. 04
      Watch the return path.

      Keep throttle hold available and treat link loss, stale telemetry, or unexpected response as a stop condition.
